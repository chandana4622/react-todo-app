# React Todo App

A simple Todo application built using React.js.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- localStorage support

## Technologies Used

- React.js
- JavaScript
- CSS
- Vite

## Installation


npm install
npm run dev


## Project Structure

```text
src/
├── components/
├── hooks/
├── App.jsx
├── main.jsx
└── index.css
```
